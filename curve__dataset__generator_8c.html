Detailed Description

Generates a CSV dataset representing a curve for ML testing.

Author
Mohammed Daniyal
Date
2025-09-26
Version
1.0

This tool creates a CSV file with two columns: an integer X value range and a corresponding calculated Y value based on the formula y = (sin(x/15))^2 * x + 10. It is useful for generating synthetic regression data for testing ML algorithms.

Usage: ./curve_dataset_generator output.csv start_x end_x

Parameters:

  • output.csv: The path to the CSV file to be generated.
  • start_x: The start integer value for the X range.
  • end_x: The end integer value for the X range.
