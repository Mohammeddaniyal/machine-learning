Detailed Description

Generic scaling tool for datasets using specified algorithm and parameters.

Author
Mohammed Daniyal
Date
2025-09-26
Version
1.0

This tool reads a CSV dataset, scales specified columns with a chosen scaling algorithm and parameters from a CSV file, then writes the scaled dataset to a target CSV file.

Usage: ./scale_double source.csv target.csv algorithm parameters_csv column1 column2 ...

Parameters:

  • source.csv: Path to input dataset CSV file.
  • target.csv: Path to output scaled dataset CSV file.
  • algorithm: Scaling algorithm name (e.g., "min_max", "z_score").
  • parameters_csv: CSV file containing scaling parameters.
  • column1, column2, ... : List of column names to scale.
