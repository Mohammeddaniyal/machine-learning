\doxysubsection{Detailed Description}
Core string matrix types and utilities. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/09-\/25
\end{DoxyDate}
This header defines opaque matrix structures specialized for string data. It provides APIs for creation, destruction, element access and mutation, CSV import/export, matrix transpose, shuffle, copy, and column deletion.\hypertarget{dmlfw__mat__string_8h_autotoc_md9}{}\doxysubsubsection{\texorpdfstring{Error Handling\+:}{Error Handling:}}\label{dmlfw__mat__string_8h_autotoc_md9}
All functions report errors via the centralized error API. Use {\ttfamily \doxylink{dmlfw__error_8h_a3e8543135c572122fa434e82586b04fe}{dmlfw\+\_\+error()}} to check for errors after calls. {\ttfamily \doxylink{dmlfw__error_8h_a2a80986d26481880229bd8371445c125}{dmlfw\+\_\+get\+\_\+error\+\_\+string()}} and {\ttfamily \doxylink{dmlfw__error_8h_ad50e40b8f20fac982ff9d41c1b3648b2}{dmlfw\+\_\+get\+\_\+debug\+\_\+string()}} provide error information.\hypertarget{dmlfw__mat__string_8h_autotoc_md10}{}\doxysubsubsection{\texorpdfstring{Ownership\+:}{Ownership:}}\label{dmlfw__mat__string_8h_autotoc_md10}
Functions returning new matrix pointers transfer ownership to the caller, who is responsible for freeing with {\ttfamily \doxylink{dmlfw__mat__string_8h_a955ef259ca85279ff3939af6c0a9212c}{dmlfw\+\_\+mat\+\_\+string\+\_\+destroy()}}.\hypertarget{dmlfw__mat__string_8h_autotoc_md11}{}\doxysubsubsection{\texorpdfstring{Indexing Notes\+:}{Indexing Notes:}}\label{dmlfw__mat__string_8h_autotoc_md11}
All indices are zero-\/based.
