\doxysubsection{Detailed Description}
Core singly linked list type for double precision data. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/09-\/25
\end{DoxyDate}
This module provides a singly linked list (forward list) implementation for double precision floating point data. It supports creating, destroying, inserting elements, converting the list to a row vector, querying size, and clearing elements.\hypertarget{dmlfw__list__double_8h_autotoc_md2}{}\doxysubsubsection{\texorpdfstring{Error Handling\+:}{Error Handling:}}\label{dmlfw__list__double_8h_autotoc_md2}
All functions report errors through a centralized error API. Use {\ttfamily \doxylink{dmlfw__error_8h_a3e8543135c572122fa434e82586b04fe}{dmlfw\+\_\+error()}} to check for errors after each call. {\ttfamily \doxylink{dmlfw__error_8h_a2a80986d26481880229bd8371445c125}{dmlfw\+\_\+get\+\_\+error\+\_\+string()}} and {\ttfamily \doxylink{dmlfw__error_8h_ad50e40b8f20fac982ff9d41c1b3648b2}{dmlfw\+\_\+get\+\_\+debug\+\_\+string()}} provide diagnostic messages.\hypertarget{dmlfw__list__double_8h_autotoc_md3}{}\doxysubsubsection{\texorpdfstring{Ownership\+:}{Ownership:}}\label{dmlfw__list__double_8h_autotoc_md3}
The list owns its nodes and their double values. The vector returned by conversion functions must be explicitly freed by callers.
