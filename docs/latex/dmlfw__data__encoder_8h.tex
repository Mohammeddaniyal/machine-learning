\doxysubsection{Detailed Description}
Categorical and binary feature encoding utilities. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/09-\/25
\end{DoxyDate}
This module provides functions for encoding categorical/textual data columns from CSV files into numerical formats suitable for ML models. Supported encoding schemes include one-\/hot and binary encoding, with a generic dispatcher for algorithm selection.\hypertarget{dmlfw__data__encoder_8h_autotoc_md0}{}\doxysubsubsection{\texorpdfstring{Error Handling\+:}{Error Handling:}}\label{dmlfw__data__encoder_8h_autotoc_md0}
All functions report errors via the centralized error API. Use {\ttfamily \doxylink{dmlfw__error_8h_a3e8543135c572122fa434e82586b04fe}{dmlfw\+\_\+error()}} after function calls to check for errors. Retrieve error and diagnostic details with {\ttfamily \doxylink{dmlfw__error_8h_a2a80986d26481880229bd8371445c125}{dmlfw\+\_\+get\+\_\+error\+\_\+string()}} and {\ttfamily \doxylink{dmlfw__error_8h_ad50e40b8f20fac982ff9d41c1b3648b2}{dmlfw\+\_\+get\+\_\+debug\+\_\+string()}}.\hypertarget{dmlfw__data__encoder_8h_autotoc_md1}{}\doxysubsubsection{\texorpdfstring{Ownership\+:}{Ownership:}}\label{dmlfw__data__encoder_8h_autotoc_md1}
All allocated resources are cleaned up internally on error and after completion. No ownership is transferred to caller.
