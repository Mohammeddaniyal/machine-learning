\doxysubsection{Detailed Description}
Gradient descent configuration data structures and APIs. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/09-\/25
\end{DoxyDate}
This module provides definitions and management functions for gradient descent configuration objects used with ML algorithms such as linear regression. It enables detailed customization of learning rate, iterations, gradient descent type, progress callbacks, data provisioning, and mini-\/batch processing.\hypertarget{dmlfw__ml__configurations_8h_autotoc_md14}{}\doxysubsubsection{\texorpdfstring{Error Handling\+:}{Error Handling:}}\label{dmlfw__ml__configurations_8h_autotoc_md14}
All functions validate input parameters and report errors via the centralized error API. After function calls, check {\ttfamily \doxylink{dmlfw__error_8h_a3e8543135c572122fa434e82586b04fe}{dmlfw\+\_\+error()}} to detect if an error occurred. Retrieve descriptive error messages with {\ttfamily \doxylink{dmlfw__error_8h_a2a80986d26481880229bd8371445c125}{dmlfw\+\_\+get\+\_\+error\+\_\+string()}} and diagnostic info with {\ttfamily \doxylink{dmlfw__error_8h_ad50e40b8f20fac982ff9d41c1b3648b2}{dmlfw\+\_\+get\+\_\+debug\+\_\+string()}}.
