Command-\/line tool to split a dataset CSV into test and training sets. \texorpdfstring{$<$}{<}\texorpdfstring{$>$}{>}

This tool loads a dataset as a double matrix, shuffles it multiple times, and splits it into a test (minor) set and a training (major) set based on a specified minor percentage. The resulting datasets are saved to two separate CSV files.

Usage\+: ./create\+\_\+test\+\_\+train\+\_\+dataset dataset.\+csv test.\+csv train.\+csv minor\+\_\+percentage

Parameters\+:
\begin{DoxyItemize}
\item dataset.\+csv\+: Input dataset CSV file path.
\item test.\+csv\+: Output CSV file path for test subset.
\item train.\+csv\+: Output CSV file path for training subset.
\item minor\+\_\+percentage\+: Percentage of rows for the test set (1-\/50).
\end{DoxyItemize}

This tool uses ml-\/framework matrix modules for data manipulation.
