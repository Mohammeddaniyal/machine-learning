Core double precision matrix types and utilities.

1.\+0

\begin{DoxyDate}{Date}

This header defines opaque matrix structures for double precision floating-\/point data. It provides APIs for creation, destruction, element access and mutation, CSV import/export, matrix operations such as transpose, reshape, shuffle, block extraction, and statistical functions.\hypertarget{dmlfw__mat__double_8h_autotoc_md6}{}\doxysubsubsection{\texorpdfstring{Error Handling\+:}{Error Handling:}}\label{dmlfw__mat__double_8h_autotoc_md6}
