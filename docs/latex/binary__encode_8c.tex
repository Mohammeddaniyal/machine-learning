Command-\/line tool to encode specified CSV columns into binary format.

This tool reads an input CSV file and converts specified columns to binary encoding, which is useful for preprocessing categorical features for machine learning models using the ml-\/framework\textquotesingle{}s encoder module.

Usage\+: ./binary\+\_\+encode source.\+csv target.\+csv column1 column2 ...

Parameters\+:
\begin{DoxyItemize}
\item source\+\_\+csv\+: Path to the input CSV file.
\item target\+\_\+csv\+: Path to the output CSV file where encoded data will be saved.
\item columns\+\_\+to\+\_\+encode\+: List of column names to apply binary encoding on.
\end{DoxyItemize}

This tool uses the functions from the ml-\/framework encoder and vector modules ({\ttfamily \doxylink{dmlfw__encoder_8h}{dmlfw\+\_\+encoder.\+h}}, {\ttfamily \doxylink{dmlfw__vector_8h}{dmlfw\+\_\+vector.\+h}}).
