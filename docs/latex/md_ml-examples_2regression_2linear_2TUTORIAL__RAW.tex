\hypertarget{md_ml-examples_2regression_2linear_2TUTORIAL__RAW_autotoc_md30}{}\doxysection{\texorpdfstring{Important Note About Preprocessing Tools}{Important Note About Preprocessing Tools}}\label{md_ml-examples_2regression_2linear_2TUTORIAL__RAW_autotoc_md30}
The examples in this tutorial assume you have copied or installed the preprocessing tools (such as {\ttfamily create\+\_\+test\+\_\+train\+\_\+dataset}, {\ttfamily polynomial\+\_\+dataset\+\_\+generator}, {\ttfamily scale\+\_\+dataset}, etc.) into a directory included in your system\textquotesingle{}s executable {\ttfamily PATH}, for example {\ttfamily /usr/bin}. This allows you to run these tools simply by their names without specifying full or relative paths.

If you have not done this, you need to run the tools by specifying their full or relative paths, for example\+:


\begin{DoxyCode}{0}
\DoxyCodeLine{../../tools/build/create\_test\_train\_dataset\ ...}

\end{DoxyCode}

\begin{DoxyItemize}
\item Use the provided tools to split data, generate polynomial features, and scale datasets step-\/by-\/step. ~\newline

\item Always let training finish the configured iterations to save the model. Interrupting early loses progress. ~\newline

\item Evaluate models using {\ttfamily gd\+\_\+test\+\_\+model} on generated model CSV files. ~\newline

\item Repeat for other datasets by following analogous preprocessing steps. 
\end{DoxyItemize}
