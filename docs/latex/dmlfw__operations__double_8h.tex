\doxysubsection{Detailed Description}
Core double precision vector and matrix arithmetic operations. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/09-\/25
\end{DoxyDate}
This module provides fundamental arithmetic operations specialized for double precision vectors and matrices, including multiplication, addition, subtraction, scalar scaling, and advanced matrix multiplication algorithms like Strassen’s method.\hypertarget{dmlfw__operations__double_8h_autotoc_md18}{}\doxysubsubsection{\texorpdfstring{Error Handling\+:}{Error Handling:}}\label{dmlfw__operations__double_8h_autotoc_md18}
Functions validate all input pointers and vector/matrix dimensions. Errors are reported through a centralized error API. After calling functions, check {\ttfamily \doxylink{dmlfw__error_8h_a3e8543135c572122fa434e82586b04fe}{dmlfw\+\_\+error()}} and retrieve error details via {\ttfamily \doxylink{dmlfw__error_8h_a2a80986d26481880229bd8371445c125}{dmlfw\+\_\+get\+\_\+error\+\_\+string()}} and {\ttfamily \doxylink{dmlfw__error_8h_ad50e40b8f20fac982ff9d41c1b3648b2}{dmlfw\+\_\+get\+\_\+debug\+\_\+string()}}.\hypertarget{dmlfw__operations__double_8h_autotoc_md19}{}\doxysubsubsection{\texorpdfstring{Ownership\+:}{Ownership:}}\label{dmlfw__operations__double_8h_autotoc_md19}
Inputs are owned by the caller. Functions allocate new output vectors/matrices if corresponding pointers are {\ttfamily NULL}. Any allocated output vectors/matrices are owned by the caller who must free them.
