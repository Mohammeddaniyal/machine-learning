\doxysubsection{Detailed Description}
Core unordered string set types and utilities. 

\begin{DoxyVersion}{Version}

\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/09-\/25

This header defines opaque unordered set structures specialized for string data. It provides APIs for creation, destruction, element access, adding unique strings, and querying the set size.\hypertarget{dmlfw__set__string_8h_autotoc_md22}{}\doxysubsubsection{\texorpdfstring{Error Handling\+:}{Error Handling:}}\label{dmlfw__set__string_8h_autotoc_md22}
All functions report errors via the centralized error API. Use {\ttfamily \doxylink{dmlfw__error_8h_a3e8543135c572122fa434e82586b04fe}{dmlfw\+\_\+error()}} to check for errors after calls. {\ttfamily \doxylink{dmlfw__error_8h_a2a80986d26481880229bd8371445c125}{dmlfw\+\_\+get\+\_\+error\+\_\+string()}} and {\ttfamily \doxylink{dmlfw__error_8h_ad50e40b8f20fac982ff9d41c1b3648b2}{dmlfw\+\_\+get\+\_\+debug\+\_\+string()}} provide diagnostic details.\hypertarget{dmlfw__set__string_8h_autotoc_md23}{}\doxysubsubsection{\texorpdfstring{Ownership\+:}{Ownership:}}\label{dmlfw__set__string_8h_autotoc_md23}
Functions returning new set pointers transfer ownership to the caller, who is responsible for freeing with {\ttfamily \doxylink{dmlfw__set__string_8h_ae9f566880579332b68c428fdec0d0e11}{dmlfw\+\_\+set\+\_\+string\+\_\+destroy()}}. Returned strings from get operations are allocated and must be freed by callers.
