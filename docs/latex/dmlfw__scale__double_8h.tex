\doxysubsection{Detailed Description}
Matrix data scaling and normalization using double precision. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/09-\/25
\end{DoxyDate}
This module provides scaling algorithms applied to double precision matrices, such as min-\/max normalization and z-\/score standardization.

Algorithms include\+:
\begin{DoxyItemize}
\item Min-\/\+Max scaling (rescale to \mbox{[}0,1\mbox{]})
\item Z-\/\+Score scaling (mean 0, standard deviation 1)
\end{DoxyItemize}

Functions support loading scaling parameters from files and applying previously computed parameters to new data.\hypertarget{dmlfw__scale__double_8h_autotoc_md20}{}\doxysubsubsection{\texorpdfstring{Error Handling\+:}{Error Handling:}}\label{dmlfw__scale__double_8h_autotoc_md20}
All functions validate input parameters and interoperability. Errors are reported via the centralized error API, using {\ttfamily \doxylink{dmlfw__error_8h_a3e8543135c572122fa434e82586b04fe}{dmlfw\+\_\+error()}}, {\ttfamily \doxylink{dmlfw__error_8h_a2a80986d26481880229bd8371445c125}{dmlfw\+\_\+get\+\_\+error\+\_\+string()}}, and {\ttfamily \doxylink{dmlfw__error_8h_ad50e40b8f20fac982ff9d41c1b3648b2}{dmlfw\+\_\+get\+\_\+debug\+\_\+string()}}.\hypertarget{dmlfw__scale__double_8h_autotoc_md21}{}\doxysubsubsection{\texorpdfstring{Ownership\+:}{Ownership:}}\label{dmlfw__scale__double_8h_autotoc_md21}
Caller owns all input matrices. Output matrices are allocated if {\ttfamily NULL} is passed, and ownership passes to the caller, who must free them.
