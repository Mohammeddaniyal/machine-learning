Command-\/line tool to cut specified columns from a CSV file.

This tool loads a CSV file into a string matrix, removes specified columns by name, and saves the resulting matrix to a new CSV file. It helps extract subsets of data for preprocessing or analysis using the ml-\/framework matrix and utility modules.
