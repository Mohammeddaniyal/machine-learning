Usage\+: ./encode\+\_\+binary input\+\_\+file output\+\_\+file column\+\_\+name1 column\+\_\+name2 ...

\item output\+\_\+file\+: Path to the output CSV file with encoded columns.
\item column\+\_\+name(s)\+: One or more column names to apply binary encoding.
\end{DoxyItemize}
