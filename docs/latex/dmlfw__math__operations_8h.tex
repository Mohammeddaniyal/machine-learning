\doxysubsection{Detailed Description}
Core mathematical vector and matrix functions. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/09-\/25
\end{DoxyDate}
This module provides functions for common mathematical transformations (sigmoid, log) and reductions (sum) on double precision vectors and matrices, supporting ML and numeric data workflows.\hypertarget{dmlfw__math__operations_8h_autotoc_md4}{}\doxysubsubsection{\texorpdfstring{Error Handling\+:}{Error Handling:}}\label{dmlfw__math__operations_8h_autotoc_md4}
All functions use a centralized error API. After calls, check {\ttfamily \doxylink{dmlfw__error_8h_a3e8543135c572122fa434e82586b04fe}{dmlfw\+\_\+error()}} and access full details via {\ttfamily \doxylink{dmlfw__error_8h_a2a80986d26481880229bd8371445c125}{dmlfw\+\_\+get\+\_\+error\+\_\+string()}} and {\ttfamily \doxylink{dmlfw__error_8h_ad50e40b8f20fac982ff9d41c1b3648b2}{dmlfw\+\_\+get\+\_\+debug\+\_\+string()}}.\hypertarget{dmlfw__math__operations_8h_autotoc_md5}{}\doxysubsubsection{\texorpdfstring{Ownership\+:}{Ownership:}}\label{dmlfw__math__operations_8h_autotoc_md5}
Functions that allocate new containers (vectors/matrices) transfer ownership to caller. Returned vectors/matrices must be destroyed with the appropriate API function.
