\chapter{Daniyal Machine Learning Framework (DMLFW)}
\hypertarget{index}{}\label{index}\index{Daniyal Machine Learning Framework (DMLFW)@{Daniyal Machine Learning Framework (DMLFW)}}
\hypertarget{index_intro}{}\doxysection{\texorpdfstring{Introduction}{Introduction}}\label{index_intro}
DMLFW is a hands-\/on educational framework to learn core machine learning concepts in C, from scratch. It provides core data structures, gradient descent implementations, preprocessing utilities, and evaluation metrics with visual outputs.

Git\+Hub repository\+: \href{https://github.com/Mohammeddaniyal/machine-learning.git}{\texttt{ https\+://github.\+com/\+Mohammeddaniyal/machine-\/learning.\+git}}\hypertarget{index_features}{}\doxysection{\texorpdfstring{Features}{Features}}\label{index_features}

\begin{DoxyItemize}
\item {\bfseries{Data Structures\+:}} Vectors, matrices, lists (double and string). ~\newline

\item {\bfseries{Mathematical Utilities\+:}} Algebra, statistics, transformations. ~\newline

\item {\bfseries{Algorithms\+:}} Batch, stochastic, and mini-\/batch gradient descent. ~\newline

\item {\bfseries{Data Preprocessing\+:}} Encoding, normalization, scaling. ~\newline

\item {\bfseries{Evaluation Metrics\+:}} R2 score, accuracy. ~\newline

\item {\bfseries{Error Handling \& Utilities\+:}} Centralized error reporting and file/string tools.
