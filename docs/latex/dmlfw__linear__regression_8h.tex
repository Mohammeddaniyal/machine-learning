\doxysubsection{Detailed Description}
Gradient descent-\/based linear regression training and prediction. 

\begin{DoxyVersion}{Version}
1.\+0 
\end{DoxyVersion}
\begin{DoxyDate}{Date}
2025-\/09-\/25
\end{DoxyDate}
This module provides APIs to fit linear regression models using batch, stochastic, and mini-\/batch gradient descent methods, including support for regularization and user-\/defined progress callbacks. It also offers prediction functionality from trained models.\hypertarget{dmlfw__linear__regression_8h_autotoc_md12}{}\doxysubsubsection{\texorpdfstring{Error Handling\+:}{Error Handling:}}\label{dmlfw__linear__regression_8h_autotoc_md12}
Functions use centralized error reporting. Call {\ttfamily \doxylink{dmlfw__error_8h_a3e8543135c572122fa434e82586b04fe}{dmlfw\+\_\+error()}} after function execution to check for errors. For error details, use {\ttfamily \doxylink{dmlfw__error_8h_a2a80986d26481880229bd8371445c125}{dmlfw\+\_\+get\+\_\+error\+\_\+string()}} and {\ttfamily \doxylink{dmlfw__error_8h_ad50e40b8f20fac982ff9d41c1b3648b2}{dmlfw\+\_\+get\+\_\+debug\+\_\+string()}}.\hypertarget{dmlfw__linear__regression_8h_autotoc_md13}{}\doxysubsubsection{\texorpdfstring{Ownership\+:}{Ownership:}}\label{dmlfw__linear__regression_8h_autotoc_md13}
Returned vectors representing trained models or predictions must be freed using the vector destroy API to avoid memory leaks.
