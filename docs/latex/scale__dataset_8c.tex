This tool reads a CSV dataset, scales specified columns with a chosen scaling algorithm and parameters from a CSV file, then writes the scaled dataset to a target CSV file.

Usage\+: ./scale\+\_\+double source.\+csv target.\+csv algorithm parameters\+\_\+csv column1 column2 ...

Parameters\+:
\begin{DoxyItemize}
\item source.\+csv\+: Path to input dataset CSV file.
\item target.\+csv\+: Path to output scaled dataset CSV file.
\item algorithm\+: Scaling algorithm name (e.\+g., "{}min\+\_\+max"{}, "{}z\+\_\+score"{}).
\item parameters\+\_\+csv\+: CSV file containing scaling parameters.
\item column1, column2, ... \+: List of column names to scale.
